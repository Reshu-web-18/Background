# Background # 🌸 Nature View

A simple and responsive webpage created using HTML and CSS. This project displays a beautiful nature background with a centered heading and description.

 📌 Features
- Beautiful full-screen background image
- Centered text content
- Clean and simple UI
- Responsive background using `background-size: cover`

🛠️ Technologies Used
- HTML5
- CSS3

 📂 Project Structure

```
Nature-View/
│── index.html
│── Screenshot_1-10-2026_203125_.jpeg
│── README.md
```

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.

 📸 Preview

The webpage displays:
- **Title:** Nature View
- **Description:** Capture the moments of beautiful flowers
- A full-screen nature background image.

> **Note:** Make sure the image file `Screenshot_1-10-2026_203125_.jpeg` is in the same folder as `index.html`. Otherwise, the background image will not appear.
